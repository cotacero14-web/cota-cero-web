# Cota Cero — sitio web

Sitio estático, sin build. Abrir `index.html` (o servir la carpeta: `python -m http.server`).

- `index.html` + `site.css` + `site.js` — landing, implementación del `COTA CERO/Keyvisual.ai`.
- `catalogo.html` — catálogo de proyectos (Ideación · Diseño · Ejecución), mismo sistema de marca.
- `fonts/` — PP Neue Gstaad y Maison Neue Mono en woff2. **Verificar licencia web** de PP Neue Gstaad (Pangram Pangram) antes de publicar.
- `brand/` — logos e isotipos SVG. Los símbolos `#wm` e `#iso` van inline en cada HTML.
- `PRODUCT.md` / `DESIGN.md` — contexto y sistema visual.
- `COTA CERO/` — material fuente de la marca (no se publica).
